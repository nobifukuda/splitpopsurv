Split-Population Survival Models

Accelerated failure-time regression combined with a logit regression on the surviving fraction — an R port of the original Stata ml programs, grounded in Yamaguchi's mover–stayer framework.

R package by Nobutaka Fukuda (Tohoku University) · Theory: Yamaguchi & Ferguson (1995), Yamaguchi (1998)

Sm(t) — susceptible ("mover") survival, decaying toward 0

p — the surviving fraction ("stayers") who never fail

§overview

What this package does

Ordinary survival regressions assume every subject will eventually experience the event if followed long enough. That assumption fails when part of the population is structurally immune — women who have stopped childbearing for good, recidivists who never reoffend, marriages that never end in divorce. A split-population (or cure, or mover–stayer) model separates two questions that an ordinary hazard model conflates: who never experiences the event at all, and for those who do, when.

The package fits five baseline distributions for the timing part — log-logistic, Weibull, log-normal, gamma, and the generalized gamma that nests all four — each paired with a logistic regression on the probability of ultimately belonging to the immune ("stayer") group. It is a direct R translation of five Stata ml programs, each exposed as one fit_splitpop_*() function.

01the model

Two regressions, one likelihood

Following Yamaguchi & Ferguson (1995, eqs. 3–6) and Yamaguchi (1998, eq. 1–2), every subject belongs to one of two latent classes. Movers are at risk and eventually fail according to a duration distribution; stayers have zero risk and never do. The proportion of stayers, p, and the timing distribution for movers are estimated jointly, each with its own covariates.

Mixture survival and density

Let Sm(t) and fm(t) be the conditional survival and density for movers, and p the stayer probability. The marginal (population) survival and density are:

S(t)= (1 − p) Sm(t) + p
f(t)= (1 − p) fm(t)

As t → ∞, S(t) → p — the plateau in the hero figure above.

The two regression equations

Every fit_splitpop_*() call takes two formulas, matching the Stata code's two named equations:

H_regressionlog(T) = X′β + σz   (location/scale of the mover distribution)
P_regressionlogit(p) = X′α   (probability of being a stayer)

For the generalized gamma, z follows the extended log-gamma distribution with shape λ (Prentice 1974) — the family that nests Weibull (λ=1), log-normal (λ=0), and gamma (σ=1) as special cases, exactly as in Yamaguchi & Ferguson (1995, p. 283, note 10).

The log-likelihood

The correct hazard-based log-likelihood contribution per subject i (event indicator δi) is:

ℓi = δi log f(ti) + (1 − δi) log S(ti)

equivalently, in terms of the true marginal hazard h(t) = f(t)/S(t):

ℓi = δi log h(ti) + log S(ti)

This is Yamaguchi's equation (2)–(3) (1998, p. 332), and it is what every loglik_splitpop_*() function in this package computes — see the correction below for why that division matters.

02likelihood correction

A discrepancy found in the original Stata code

All five Stata programs (SphLog, SphWieb, SphNom, SphGam, SphGGam) compute a quantity named hz2/mhz as (1-p)*hz*sv — the mover hazard times the mover survival — and then evaluate lnf = $ML_y2*ln(hz2) + ln(sv2).

(1-p)·hm(t)·Sm(t) is algebraically the marginal density f(t), not the marginal hazard h(t) = f(t)/S(t) — the code never divides by the marginal survival sv2. Plugged into δ·log(hazard) + log(survival), using density in place of hazard double-counts log S(t) for every observed event.

Verified by simulation

20,000 observations were simulated from a split-population Weibull model with known parameters, then fit both ways.

The cure-probability (P_regression) coefficients are the most visibly biased under the as-translated formula — more than double the true intercept. The corrected formula recovers all five parameters closely.

This R package implements the corrected formula throughout, written as ifelse(event == 1, log(marginal density), log(marginal survival)) — which is both the statistically correct form and, as a side effect, numerically safer: it never forms hazard = density / survival and so cannot hit the Inf × 0 → NaN trap that occurs when survival underflows to exactly zero at extreme durations.

03distributions

The five baseline distributions

Each distribution supplies the mover survival Sm(t) and density fm(t) plugged into the mixture formulas above. θ1 = Xh′β is the H_regression linear index in every case.

Log-logistic

2 free shape params
Stata: SphLog · R: fit_splitpop_loglogistic()

Survival

Sm(t) = 1 / (1 + (λt)σ)

Parameters

λ = exp(−θ₁)  ·  σ = 1/θ₂

θ₂ is a free scalar (Stata's unnamed ancillary equation, ()).

Weibull

special case: λ = 1
Stata: SphWieb · R: fit_splitpop_weibull()

Survival

Sm(t) = exp(−eθ₁tλ)

Parameters

σ = exp(−θ₁)  ·  λ = exp(ln_sigma)

Kept exactly as in the Stata source: σ and λ are computed from the equations their opposite labels would suggest — preserved literally rather than "corrected", since it doesn't affect the fitted curves, only the internal naming.

Log-normal

special case: λ = 0
Stata: SphNom · R: fit_splitpop_lognormal()

Survival

Sm(t) = 1 − Φ((ln t − θ₁)/σ)

Parameters

σ = exp(ln_sigma)

Gamma

special case: σ = 1
Stata: SphGam · R: fit_splitpop_gamma()

Survival

Sm(t) = 1 − P(κ, θ₁t)

Parameters

κ = kappa  (shape, free scalar)

P(·,·) is the regularized lower incomplete gamma function (pgamma() in R). Unlike the other four models, θ₁ here is used directly as a rate — not exponentiated — so it must stay positive; see Practical notes.

Generalized Gamma

nests all four above
Stata: SphGGam (d0 method) · R: fit_splitpop_ggamma()

The extended log-gamma error term of Prentice (1974) / Yamaguchi & Ferguson (1995, note 10). Four free parameters per subject: θ₁ (location, H_regression), ln_sigma (scale), kappa (shape κ), and the P_regression logit.

κ near 0→ falls back to the log-normal branch (Φ, standard normal density)
else→ generalized gamma branch via the incomplete gamma function

The Stata code's guard if abs(κ)<0.01 then κ←sign(κ)×0.01 is preserved — there's a genuine kink in the likelihood surface at that threshold; see Practical notes.

04reference

Function reference

All five fitting functions share one signature. They build design matrices from two one-sided formulas, then maximize the corrected log-likelihood with maxLik::maxLik().

fit_splitpop_{loglogistic|weibull|lognormal|gamma|ggamma}(
  hform, pform, data, time, event, group,
  start = NULL, method = "NR"
)
ArgumentTypeMeaning
hform~ x1 + x2H_regression formula — covariates for the mover timing distribution (θ₁)
pform~ z1P_regression formula — covariates for the logit on stayer probability p
datadata.frameSource data; columns referenced by hform, pform, and the four names below
time"colname"Duration variable ($ML_y1)
event"colname"1 = failure observed, 0 = censored ($ML_y2)
group"colname"0/1 indicator that flips the cure-probability logit ($ML_y3) — see Practical notes
startnumeric or NULLStarting parameter vector; each function has a sensible default (see source)
method"NR"Optimizer passed to maxLik() — try "BFGS" if Newton–Raphson fails to converge

Return value

A maxLik object. Use summary(fit) for coefficients, standard errors and a likelihood-ratio-style output (the closest analogue to Stata's ml maximize table); coef(fit), logLik(fit), and vcov(fit) also work.

Parameter naming

Coefficients are named H_regression:<term> and P_regression:<term>, plus the model's ancillary scalar(s) — theta2 (log-logistic), ln_sigma (Weibull, log-normal, generalized gamma), kappa (gamma, generalized gamma) — mirroring the Stata equation names.

05example

Worked example

Fitting a split-population Weibull model where x1 affects timing and x2 affects the probability of never failing:

# source the package file
source("split_population_survival_models.R")

# mydata needs: time, event (0/1), group (0/1), and your covariates
fit <- fit_splitpop_weibull(
  hform = ~ x1,           # H_regression: covariates for timing
  pform = ~ x2,           # P_regression: covariates for cure probability
  data  = mydata,
  time  = "time",
  event = "event",
  group = "group",
  method = "BFGS"
)

summary(fit)   # coefficients, SEs, z-values, log-likelihood
coef(fit)      # named parameter vector

To recover the fitted stayer probability for a given row, apply plogis() to the P_regression linear predictor built the same way the fitting function does — see .design_matrix() and .cure_prob() in the source for the exact construction.

07notes

Practical notes

The group flip

The cure probability is computed as p = plogis(θ_p) when group == 1, and 1 − plogis(θ_p) when group == 0 — preserved exactly from the Stata source's $ML_y3 handling. If your data has no such distinction, set group to a column of all 1s and p reduces to the ordinary logistic regression on stayer probability.

Starting values

Newton–Raphson (method = "NR", the default) can fail to converge from a poor start; "BFGS" is a more forgiving fallback. The gamma and generalized-gamma defaults deliberately start with a positive H_regression intercept and zero slopes (.safe_start_h()), because those two models use θ₁ directly as a rate — without an exp() transform — so it must stay positive.

The generalized gamma's κ = 0 kink

When |κ| < 0.01 the model switches to a separate log-normal-equivalent branch (matching the Stata guard). This is a genuine, not merely numerical, kink in the likelihood surface — if summary(fit) reports a non-finite standard error, the optimizer likely landed near that threshold; try a different starting kappa.

What has no direct R equivalent

  • ml check / ml search — evaluate the relevant loglik_splitpop_*() function once at your starting values by hand, and/or try several starts or optimizers if convergence fails.
  • ml graph — plot fitted survival/hazard curves yourself from coef(fit) plugged back into the survival/density formulas above.
